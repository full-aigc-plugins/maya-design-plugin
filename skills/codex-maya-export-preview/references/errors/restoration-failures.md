# 还原失败处置

## 什么时候会发生

- Maya 在导出期间崩溃，`cmds` 调用全部失效
- 面板被用户或脚本关闭，`modelPanel(edit=True)` 目标不存在
- 场景被外部事件改变（例如从属引用自动重载）

## 症状

`RESTORE_UNCONFIRMED` 错误，消息形如：

```
restoration mismatch on field 'current_time'
```

字段名会告诉你**哪一个**字段没回到原位。

## 处置步骤

1. **停下来。** 不要再调用任何 Maya 接口。
2. **如实报告。** 把错误码与字段名给用户，不要包装成「导出成功但有警告」。
3. **不重试。** 重试会在未知状态上叠加改动。
4. **让用户决定。** 用户可能选择：手动检查场景、撤销到保存点、或忽略（如果他知道那个字段无关紧要）。

## 不要做的事

- **不要**自动「再还原一次」。第二次还原同样可能失败，而且遮蔽了第一次的现场。
- **不要**把 `restoration_status` 写成 `restored`。诚实标记为 `unconfirmed`。
- **不要**继续走后续的发布步骤。产物可以保留，但状态未确认必须让用户知道。
