# 为什么绝不自动重试

## 政策

Playblast 失败后**不自动重试**。一次失败就是一次失败。

## 三个理由

1. **场景状态未知。** 失败可能发生在 `restored_maya_state` 内部，
   此时场景可能处于半改动状态。自动重试会在未知状态上叠加新改动。
2. **代价不可忽视。** Playblast 是本地渲染，可能耗时数分钟。
   自动重试会成倍消耗用户时间而不告知。
3. **失败通常不是瞬时的。** 相机不存在、帧数不足、模块缺失——
   这些问题不会因为重试而消失。重试只是把同一个错误再报一次。

## 用户重新发起时的正确流程

1. 先看错误码判断类别
2. 若是配置问题（帧数不足、相机名错）→ 用户修正参数
3. 若是环境问题（ABI、模块）→ 转 `codex-maya-diagnose`
4. 若疑似瞬时（磁盘满、权限）→ 用户确认环境后**手动**重新发起

## 对 Agent 的约束

Agent **不得**在同一个会话里对同一组参数连续调用两次导出。
如果需要重试，必须由用户明确说「再试一次」。
