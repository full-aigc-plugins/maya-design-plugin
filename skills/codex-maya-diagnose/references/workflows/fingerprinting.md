# 稳定指纹与日志关联

## 计算方式

```python
sha256(normalize(text)).hexdigest()[:16]
```

`normalize` 把连续空白折叠为单个空格并 strip 首尾。
因此「同一错误不同缩进 / 不同换行」产生同一指纹。

## 用途

1. **日志关联**：多次会话里同一个错误有同一个指纹，便于统计「这个错反复出现」。
2. **去重**：批量诊断时按指纹分组。
3. **回归检测**：把指纹写进测试，错误文本变化时测试变红。

## 长度选择

16 位十六进制 = 64 bit。碰撞概率在「单个项目可能出现的错误数量」量级下可忽略，
同时短到可以贴在日志行里。

## 与错误码的分工

| 维度 | 错误码 | 指纹 |
|---|---|---|
| 粒度 | 类别（5 个 + 2 个特殊） | 具体文本 |
| 稳定性 | 极高（公开契约） | 高（归一化后） |
| 用途 | 分支判断 | 关联与去重 |
| 变化频率 | 几乎不变 | 随错误文本变 |
