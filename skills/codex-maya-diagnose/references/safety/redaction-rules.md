# 脱敏规则

## 脱敏对象

**绝对路径。** 包括场景路径、Maya 安装路径、模块搜索路径、Python 可执行文件路径。

## 脱敏方式

替换为字面量 `<redacted-path>`。实现：

```python
re.sub(r"/[A-Za-z0-9_./-]*", "<redacted-path>", cleaned)
```

在 `_safe_message` 里对整条诊断消息应用，因此错误文本里的路径也被覆盖。

## 不脱敏的对象

| 对象 | 为什么保留 |
|---|---|
| 相对路径 | 不含用户身份信息 |
| 场景节点名 | 是场景内容，不是隐私 |
| 版本号 | 诊断必需 |
| 平台字符串 | 诊断必需 |
| 模块路径**数量** | 足以判断「是否为空」 |

## 环境变量

**只报类别与版本号，不报值。** 例如报 `MAYA_LOCATION` 是否设置，
但不报它指向哪里。

## 测试覆盖

`tests/test_maya_diagnostics.py::DiagnosticsRedactionTests`：
- 绝对路径在 `probe_path` 消息里被脱敏
- `diagnose` 报告里的 `maya_path` / `module_paths` 被脱敏
- 指纹对同一消息稳定

## 为什么在最靠近产生点做

在下游过滤依赖「下游记得过滤」。在最靠近产生点脱敏，
即使下游把报告原样写进日志也不会泄露。
