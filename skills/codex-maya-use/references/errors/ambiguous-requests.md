# 模糊请求的澄清话术

## 模糊模式一：只说要「用一下插件」

**话术：** 「你是想先盘点场景（检查），还是直接出图（导出）？」

## 模糊模式二：「这个场景能用吗」

**歧义：** 是问「能不能导出」还是「有没有问题」？

**话术：** 「是想确认能不能导出（先检查），还是它现在报了错（排障）？」

## 模糊模式三：「帮我处理一下这个 Maya 文件」

**歧义：** 完全没有意图信息。

**话术：** 「你希望我对它做什么——只读盘点、导出预览、还是排查某个错误？」

## 原则

- **一次只问一个问题。**
- **给出具体选项**，不要问「你想干什么」这种开放式问题。
- **不要**在澄清前先跑一个技能「探探路」。那会产生副作用。
