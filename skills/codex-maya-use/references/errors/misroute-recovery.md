# 路由错了怎么回退

## 症状

用户说「我要的是 X，你怎么做了 Y」。

## 处置

1. **承认并停下。** 不要试图在错误的路径上继续。
2. **确认目标是哪个技能。**
3. **重新路由。** 如果已经产生了副作用（例如已经启动了导出），
   如实说明已发生的动作。
4. **不要甩锅。** 路由判断是 Agent 的责任，不是用户的。

## 常见误路由

| 用户其实想要 | Agent 误用了 | 后果 |
|---|---|---|
| 排障 | 导出 | 浪费一次渲染 |
| 检查 | 导出 | 产生了不必要的产物 |
| 导出 | 检查 | 用户以为已出图 |

最后一种最危险：用户拿到一份 `scene_receipt` 误以为那是产物。
因此**回执里的 `plugin_id` 不能区分两者**（都是 `codex-maya`），
必须看是 `scene_receipt` 还是 `artifact_receipt`。
