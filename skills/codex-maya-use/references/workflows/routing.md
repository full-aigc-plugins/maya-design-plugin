# 路由判断详解

## 三分类判断

| 用户意图 | 判据 | 目标 |
|---|---|---|
| 想知道场景里有什么 | 出现「检查/看看/有哪些/列出/盘点/相机/帧范围/引用」 | `codex-maya-inspect` |
| 想拿到视频 | 出现「渲染/出图/白模/Playblast/预览/review 视频/导出」 | `codex-maya-export-preview` |
| 想解决报错 | 出现「报错/失败/为什么不行/ModuleNotFoundError/装不上」 | `codex-maya-diagnose` |

## 模糊时的澄清话术

不要替用户选。用一句话确认：

- 「你是想先看看场景里有什么（检查），还是直接出图（导出）？」
- 「你现在是遇到报错了（排障），还是想开始做（检查/导出）？」

## 不需要澄清的情况

用户说「用一下即梦插件」但上下文是「review 这版动画」——
上下文已经指明是导出。此时可以直接路由到 `codex-maya-export-preview`，
但要用一句话说明「按导出处理」。
