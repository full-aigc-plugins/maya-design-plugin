# 什么情况下不该用本技能

## 明确请求

| 用户已经说了 | 应该直接调用 |
|---|---|
| 「检查一下这个场景」 | `codex-maya-inspect` |
| 「渲染一版白模」 | `codex-maya-export-preview` |
| 「这个报错什么意思」 | `codex-maya-diagnose` |

## 为什么要加这条规则

绕经路由会：
1. 多消耗一次调用
2. 让路由技能的描述逐渐被「补全」，最终变成第二份流程文档
3. 稀释每个技能自己的触发描述，降低触发准确率

## 自检

调用本技能前问一句：**这个请求是不是已经明确对应一个技能了？**
如果是，直接调那个。
