# 不重复原则

## 规则

本技能正文**不复制**下游技能的工作流说明、字段表、错误码细节。

## 为什么

两份真相 = 改一处漏一处。下游技能改了流程，路由器不知道，
用户就会拿到过期指引。

## 允许写什么

- 路由判断表（意图 → 技能名）
- 组合场景的顺序
- 「不该用本技能」的自检

## 不允许写什么

- 下游技能的具体步骤
- 下游回执的字段表
- 下游的错误码与处置
- 代码调用示例

## 自检方式

`tests/test_skills.py::SkillAntiRoutingTests::test_router_does_not_duplicate_workflow_instructions`
断言本技能正文不含 `# Implementation` 这类下游标题。

## 需要细节时怎么办

指针，不是副本。用 `references/` 下的文件承载，或直接让用户看下游技能。
