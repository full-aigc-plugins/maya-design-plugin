# 零副作用保证

## 本技能的副作用清单

**空的。**

| 动作 | 是否执行 |
|---|---|
| 调用 Maya | 否 |
| 读写场景 | 否 |
| 启动子进程 | 否 |
| 读写文件 | 否 |
| 访问网络 | 否 |
| 安装软件 | 否 |
| 产生回执 | 否 |

## 唯一输出

一段路由文本：目标技能名 + 一句理由 + （组合场景时）顺序。

## 为什么强调这点

路由器如果开始「顺手」做事情，就变成了第二个执行器。
那会导致：
- 副作用出现在用户没预期的地方
- 路由逻辑与执行逻辑耦合，测试困难
- 用户无法通过「先问一句」来避免昂贵的操作

## 测试方式

`tests/test_skills.py::SkillAntiRoutingTests` 断言本技能正文
**不含**下游技能的工作流标题（如 `# Implementation`），
因此不会逐渐膨胀成执行器。
